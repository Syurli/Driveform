# Samples

Reference vehicles will live here as engine-independent Driveform assets and regression inputs.

Planned baseline:

- `DF-Car-01` — 4-wheel passenger vehicle
- `DF-Truck-01` — 6×6/8×8 heavy multi-axle vehicle
- `DF-Track-01` — medium tracked reference vehicle

Samples should be usable by Standalone/Jolt, Web Editor and engine integrations from the same source definition.
